# Implementation Plan: LLM-Generated Conversation Titles

**Branch**: `019-llm-conversation-titles` | **Date**: 2026-01-21 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `/specs/019-llm-conversation-titles/spec.md`

## Summary

Replace the current title generation behavior (using first message text) with LLM-generated titles. Add a new API endpoint that accepts conversation messages and a model ID, returning a succinct title generated by the LLM. Support provider-specific default title models via configuration, allowing cost optimization by using cheaper models for title generation.

## Technical Context

**Language/Version**: Python 3.13 (backend), JavaScript ES6+ (frontend)
**Primary Dependencies**: FastAPI 0.115.0, LangChain, langchain-openai, langchain-anthropic, Vue 3.4.0, Vite 5.0.0
**Storage**: File-based JSON storage (backend), N/A for frontend (server-only)
**Testing**: pytest (backend), Vitest (frontend)
**Target Platform**: Linux server (backend), Web browsers (frontend)
**Project Type**: Web application (frontend + backend)
**Performance Goals**: Title generation within 5 seconds for 95% of requests (per SC-002)
**Constraints**: Titles limited to 60 characters max
**Scale/Scope**: Single-user application with multi-provider LLM support
